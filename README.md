# deepfake for iPhone

Builds of deepfake for iPhone, and the source signing apps follow for updates.

## Install and get updates

Add this source in your signing app (FlareStore, AltStore, Feather, ESign...):

```
https://raw.githubusercontent.com/Vraypor/deepfake-ios/main/source.json
```

Then install **deepfake** from it. New builds show up there as updates.

Or download `Riff.ipa` from [Releases](../../releases) and install it with Sideloadly.
